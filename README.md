# Patient Appointment Booking System

A REST API built with Spring Boot and MySQL to manage patient appointments. This project allows you to add patients, register doctors, and book appointments between them.

## Tech Stack
- Java, Spring Boot
- Spring Data JPA
- MySQL
- Postman (for testing)

## Features
- Add and manage patients
- Add and manage doctors
- Book, view and cancel appointments

## Why I built this
I built this project to understand how REST APIs work in real backend development.
